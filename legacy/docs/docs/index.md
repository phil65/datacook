# ProcessAnalyzer: A data manipulation and analysis tool.

!!! info
    Developed by University of Wuppertal

-------------------------------------



## Features


### Import

* File importers

    * stata files
    * R files
    * CSV files
    * Excel files
    * Matlab files
    * Parquet containers
    * HDF5 containers
    * SQLite databases
    * PDFs!

* Remote importers

    * varioius public dataset libraries
    * stock data
    * clipboard
    * websites
    * Code!

### Transformations

* reshaping

    * pivot
    * frequency tables
    * melting

* data modification

    * change dtype manually / downcasting
    * sorting
    * nan handling
    * Drop duplicates
    * string operations
    * calculations
    * binning
    * rolling / expanding operations
    * Trimming / Shifting / Diff
    * reversing / transposing
    * take subset
    * splitting

### Grouping

* Time groupers
* Apply
* Transform
* Filter
* Extract
* Stats

### Statistics

* Linear regression
* Distribution plot
* Ranks
* Modes
* Correlations / Covariances
* Descriptive stats

### Plotting

* timeline plotting

### Advanced

* machine learning
* FFT
* PCA

### History

* metadata
* merges
* "undo"
* last project on restart

### Recipes

* History items as code
* Extract history as recipes
* Create custom recipes
* Apply recipes to datasets
