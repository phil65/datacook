# Starting ProcessAnalyzer from Command line

ProcessAnalyzer can get started from command line. That way you can start the program with different settings.

## Command line options

* `processanalyzer --reset` - Delete all caches and settings.
* `processanalyzer --disable-plugins` - Start program without loading plugins.
* `processanalyzer --use-default` - Start program with default settings.
* `processanalyzer --help` - Show all available command line options.
* `processanalyzer --version` - Show currently installed version number
